# Norm skill

[简体中文](README.zh-CN.md)

This repository provides the [Norm skill](SKILL.md) for coding agents working on Norm applications and modules. It directs agents to the installed CLI, language reference, library catalogs, and executable examples for the task at hand.

Add this repository as a skill source in an agent environment that supports `SKILL.md`. The skill file is the delivered instruction; this README is for human readers. Consult the [Norm documentation](https://normlanguage.github.io/Norm/) for the language and toolchain.
